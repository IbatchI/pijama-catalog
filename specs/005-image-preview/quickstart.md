## 4. Manual validation — US1 (tap / click)

```bash
npm run dev
# Open http://localhost:3000
```

| Step | Action | Expected |
|------|--------|----------|
| 1 | Click or tap a loaded product photo | Overlay opens with that product’s image, larger, aspect ratio kept |
| 2 | Confirm you are still on the same catalog page | URL unchanged; same page of results |
| 3 | Note selected size (if any) and cart count | Unchanged after close (step 4) |
| 4 | Close overlay | Card still shows same size; cart badge unchanged |

---

## 5. Manual validation — US2 (desktop hover)

Use a desktop viewport (`md` or wider, typically ≥ 768px).

| Step | Action | Expected |
|------|--------|----------|
| 1 | Hover the **photo** (not the footer) | Magnifying-glass / zoom icon appears on the image within 1s |
| 2 | Move cursor off the photo | Icon disappears |
| 3 | Hover the size pills / buttons | Zoom icon does **not** appear |
| 4 | Narrow viewport to phone width | Zoom icon never shown; tap still opens overlay |

---

## 6. Manual validation — US3 (dismiss)

| Step | Action | Expected |
|------|--------|----------|
| 1 | Open overlay → click close control | Overlay closes; focus returns to photo button |
| 2 | Open overlay → click/tap darkened backdrop | Overlay closes |
| 3 | Open overlay → press Escape | Overlay closes |
| 4 | Open overlay → Tab through controls | Focus stays inside overlay until close |

---

## 7. Edge cases

| Case | Expected |
|------|----------|
| Card with broken image | “Imagen no disponible”; tap does not open overlay |
| Open photo A, then click photo B | Single overlay; now shows B |
| Resize window while overlay open | Image stays contained and usable |
| Scroll attempt while overlay open | Catalog behind does not scroll |
