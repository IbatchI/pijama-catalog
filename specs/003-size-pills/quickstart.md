## 4. Manual Validation — US1 (Pills + Conditional CTAs)

```bash
pnpm dev
# Open http://localhost:3000
```

| Step | Action | Expected |
|------|--------|----------|
| 1 | Open any product card | 4 size pills visible; **no** action buttons |
| 2 | Tap "M 42/44" | Pill highlighted; "Agregar al carrito" + "Lo quiero" appear |
| 3 | Tap "L 46/48" | Only L highlighted; buttons still visible |
| 4 | Tap "L 46/48" again | L stays selected; buttons still visible |
| 5 | Resize to 320px width | Pills fit without horizontal scroll |

---

## 5. Manual Validation — US2 (Cart with Size)

| Step | Action | Expected |
|------|--------|----------|
| 1 | Select M on product A → Agregar | Cart badge shows 1 |
| 2 | Open cart | Row shows product name + "M 42/44" |
| 3 | Same product A, select L → Agregar | Cart badge shows 2 |
| 4 | Open cart | Two separate rows: M and L |
| 5 | Remove M row | Only L remains; badge shows 1 |
| 6 | Try adding M again on card A | "Agregar" active (M not in cart) |

---

## 6. Manual Validation — US3 (WhatsApp with Size)

| Step | Action | Expected |
|------|--------|----------|
| 1 | Select XL on any product → "Lo quiero" | WhatsApp opens |
| 2 | Check pre-filled message | Contains product name + `Talle: XL 50/52` + image URL |
| 3 | Add 2 products (sizes M and S) to cart → Finalizar | Message lists both with correct talles |
| 4 | No size selected | No way to trigger either purchase action |

**Tip**: Copy message text from URL bar (`decodeURIComponent`) to verify without sending.
